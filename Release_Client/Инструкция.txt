====================================================================
           ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ ANTIGRAVITY MANAGER
====================================================================

1. ЗАПУСК
   - Запустите файл AntigravityManager.exe
   - Программа не требует установки Python и готова к работе.

2. АКТИВАЦИЯ ДОСТУПА
   - При первом запуске откроется окно активации.
   - Скопируйте ваш уникальный Hardware ID (HWID), нажав кнопку "Копировать".
   - Отправьте HWID продавцу.
   - Полученный лицензионный ключ вставьте в поле ввода и нажмите "АКТИВИРОВАТЬ ДОСТУП".

3. СОХРАНЕНИЕ ВАШИХ АККАУНТОВ
   - Убедитесь, что Antigravity открыт и вы авторизованы в первом Google-аккаунте.
   - В менеджере нажмите "Сохранить как профиль" (например, "Основной").
   - Для добавления 2-го аккаунта нажмите "➕ Добавить новый аккаунт" -> войдите во второй Google-аккаунт в окне Antigravity -> нажмите "Сохранить как профиль" (например, "Запасной").

4. ПЕРЕКЛЮЧЕНИЕ ПРИ ОКОНЧАНИИ ЛИМИТОВ
   - Как только лимиты на текущем аккаунте исчерпаны:
   - Откройте Antigravity Manager и нажмите "⚡ Переключить" напротив запасного аккаунта.
   - Приложение автоматически сохранит изменения и перезапустит Antigravity со свежей квотой!
